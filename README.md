# What is it?

This is a simple Minecraft cheat that applies a **glowing effect** to you and the blocks and displays your coordinates along with the **block coordinates** in a separate window while playing Hide and Seek. Tested on the TeslaCraft server.

# Quick Start

1. Download and install *Minecraft Forge 1.12.2*
2. Download the *.jar* file from the GitHub Releases
3. Move the downloaded file into your *mods* folder alongside your other mods
